WEEK 2: ADVANCED DATA VISUALIZATION AND STORYTELLING WITH PYTHON

Dataset:
The public Iris flower dataset, distributed through scikit-learn. It contains flower measurements in centimetres for three Iris species. This is a classic teaching dataset; findings describe this dataset and should not be treated as a general botanical study.

Files:
- Week2_Advanced_Visualization_Report.docx: main submission report
- analysis.py: reproducible Python script
- iris_cleaned.csv: cleaned data used for the report
- correlation_matrix.csv: Pearson correlations
- descriptive_statistics.csv: descriptive statistics
- charts/: five visualizations

Run:
1. Install Python 3.
2. Run: pip install pandas numpy matplotlib scikit-learn
3. Run: python analysis.py

Story summary:
Petal length and petal width distinguish setosa from the other two species especially clearly. Versicolor and virginica overlap more, though virginica generally has larger petals. Petal length and petal width are strongly positively associated in this dataset.
